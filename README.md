## Overview
NutriMap is a county-level food vulnerability intelligence system covering 3,221 US counties. It integrates Census ACS 2021, CDC PLACES 2023, and USDA geospatial data to construct a validated NutriVulnerability Index (NVI), train three ML classifiers, perform spatial hotspot clustering, apply a greedy intervention optimizer, and deliver an interactive Folium dashboard.

## Key Results
- Counties analyzed: 3,221
- NVI Cronbach alpha: 0.928 (PASS)
- Best AUROC: 0.9349 (Logistic Regression) [95% CI: 0.926-0.943]
- AUPRC: 0.8846
- DBSCAN clusters: 80 (silhouette = 0.481)
- Optimizer: +6.5 SD above 1,000 random placements (100th percentile)
- Priority sites selected: 15

## Quickstart

Step 1 - Install dependencies:
pip install -r requirements.txt

Step 2 - Launch notebook:
jupyter notebook

Step 3 - Open and run:
NutriHog_Of_Ozarks.ipynb (Kernel > Restart and Run All)

The notebook auto-downloads all data from public APIs (Census ACS, CDC PLACES, USDA TIGER) on first run. No manual data download required. A synthetic fallback dataset is used automatically if APIs are unavailable.

## Data Access and Reproducibility
All input data is fetched automatically from free federal APIs on first run:
- US Census Bureau API: https://api.census.gov/data/2021/acs/acs5
- CDC PLACES API: https://data.cdc.gov/resource/swc5-untb.csv
- USDA TIGER Gazetteer: https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2021_Gazetteer/

After first run, the notebook caches data locally as nutrihog_county_data.csv. This file is excluded from the repo because it is auto-generated. All scored outputs (nutrimap_scored_dataset.csv, priority_sites.csv) are also auto-generated by the notebook.
